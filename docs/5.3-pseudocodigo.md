## Pseudocódigo del Evaluador de Fórmulas

```pseint
Algoritmo EvaluadorFormulas
    Definir formula Como Cadena
    Definir tokens Como Lista
    Definir resultado Como Real
    
    Leer formula
    Si Subcadena(formula, 1, 1) == "=" Entonces
        tokens <- Tokenizar(Subcadena(formula, 2, Longitud(formula)))
        resultado <- EvaluarExpresion(tokens)
        Escribir resultado
    Sino
        Escribir formula
    FinSi
FinAlgoritmo
