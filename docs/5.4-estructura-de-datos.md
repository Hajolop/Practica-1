# 5.4 Estructura de Datos

## Modelo de Almacenamiento
El estado de la hoja de cálculo se representa internamente mediante un **Objeto JavaScript (Hash Map / Clave-Valor)**, donde la clave corresponde a la coordenada de la celda (ej. `A1`) y el valor contiene la información ingresada y evaluada.

```javascript
// Estructura del objeto HojaClara en memoria y localStorage
const hojaDeCalculo = {
  "A1": { raw: "=B1+10", evaluated: "25" },
  "B1": { raw: "15", evaluated: "15" },
  "C1": { raw: "Hola", evaluated: "Hola" }
};
