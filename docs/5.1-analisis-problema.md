# 5.1 Análisis del Problema

## Definición del Proyecto
**HojaClara** es una aplicación web interactiva que simula una hoja de cálculo liviana orientada a la resolución de operaciones aritméticas básicas y evaluación de expresiones textuales dentro de una cuadrícula de celdas.

## Objetivos
* **General:** Desarrollar una interfaz reactiva en JavaScript nativo que procese celdas interconectadas, fórmulas aritméticas y persistencia de datos local.
* **Específicos:**
  * Implementar un tokenizador y evaluador de expresiones matemáticas dinámico.
  * Mantener el estado de la hoja utilizando almacenamiento local (`localStorage`).
  * Ofrecer una interfaz gráfica limpia y responsiva para la navegación entre celdas.

## Entradas, Procesos y Salidas
* **Entradas:** Texto o fórmulas ingresadas por el usuario en las celdas (ej. `=A1+B1` o valores directos `150`).
* **Procesos:**
  * Parseo y tokenización de fórmulas.
  * Evaluación de operadores aritméticos (`+`, `-`, `*`, `/`).
  * Conversión de coordenadas de celdas (filas y columnas) a valores almacenados.
* **Salidas:** Renderizado del valor evaluado en la celda correspondiente y actualización del modelo interno.
